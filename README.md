# مملكة العقار المباشر DZ

منصة عقارية جزائرية للتواصل المباشر بين أصحاب العقارات والباحثين عنها.

## أهداف المشروع

- نشر إعلانات العقارات مجانًا.
- البحث حسب الولاية والمدينة ونوع العقار.
- عرض العقارات للبيع والكراء.
- حماية أرقام الهواتف وإظهارها بعد الدفع.
- منع تكرار الإعلانات.
- مراجعة الإعلانات قبل نشرها.
- توفير تجربة استخدام احترافية على الهواتف.

## الأقسام

- شقق ومنازل للبيع.
- شقق ومنازل للكراء.
- أراضٍ للبناء.
- أراضٍ فلاحية.
- محلات ومكاتب ومستودعات.

## الحالة

المشروع قيد التطوير.
